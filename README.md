# JoyFlow 长隆全旅程动态体验编排系统

> 从被动“智慧伴游”，到主动体验编排。

JoyFlow 面向长隆乐园、演艺、餐饮、零售与酒店组成的多业态体验网络。系统持续理解家庭目标、游客状态和园区变化，在排队、天气、场次或体验负荷发生变化时重新编排行程，并把已经发生的快乐沉淀为可收藏、可分享、可延续的家庭记忆。

JoyFlow 不是另一个 AI 导游。路线由确定性模块在硬约束内生成和排序，大模型只负责理解自然语言、解释调整原因与完成陪伴式互动，不直接计算路线，也不能绕过身高、预约、闭园时间等规则。

## 核心链路

```text
游客目标与约束
    ↓
游客动态状态模型
    ↓
排队 / 天气 / 核销 / 场次 / 主动反馈
    ↓
事件触发
    ↓
候选路线生成与硬约束过滤
    ↓
确定性评分排序
    ↓
LLM 解释 + 用户确认
    ↓
状态更新、体验收藏与游后记忆
```

## MVP

首个 MVP 只验证一条完整闭环：

- 一个三口之家
- 8 个核心项目
- 1 场固定演出
- 1 个餐饮节点
- 1 套体验收藏卡
- 三类事件：排队暴增、降雨、体验负荷升高

MVP 使用模拟闸机、核销、排队和天气事件，不宣称已经接入长隆真实票务、定位或预约接口。

## 关键边界

- 体验负荷只依据年龄段、活动水平、连续游玩时长、项目强度、步行与休息做低置信度估计；超过阈值时先询问用户。
- 不使用摄像头情绪识别，不把推断当成事实。
- 商业服务只在体验完成后自然接力，不作为路线的首要优化目标。
- 所有效果数字均需由模拟、可用性测试或后续试点验证。
